02 PRIMEIROS PASSOS
Pequena por fora.
WebAssembly por dentro.

        

          
A Lume é um protótipo de linguagem compilada para este playground. O compilador converte uma pequena sintaxe diretamente em um módulo WASM binário — sem bibliotecas de compilação externas. Inclui um heap numérico controlado pelo host, com limite por execução.

          

            
01
Escreva
Use fn para funções, let para variáveis e tipos explícitos como i32, f64 e bool.
fn soma(a: i32, b: i32) -> i32 {
  return a + b;
}

            
02
Compile
Um analisador léxico e sintático transforma o programa em instruções WebAssembly. Erros apontam linha e coluna.
let ativo: bool = true;
let pi: f64 = 3.14;
if ativo { print_f64(pi); }

            
03
Conecte
A API DOM tipada aceita apenas alvos registrados e agrupa escritas sem interpretar HTML.
fn main() -> i32 {
  dom_set_i32(1, 42);
  dom_set_visible(3, true);
  return 42;
}

          

          
NOTA DE ESCOPO
O heap aceita somente células i32 por handles — sem ponteiros ou exposição de páginas de memória. Começa em 64 KiB, cresce até 16 MiB e limita blocos vivos a 16.384; alocações são zeradas, podem ser compactadas e são liberadas ao encerrar a execução. A API DOM limita escrita a alvos registrados e usa textContent. Isso reduz a superfície de injeção, mas Worker e WebAssembly não são uma sandbox para código hostil; execute somente programas confiáveis. Desempenho varia por tarefa: WASM não é automaticamente mais rápido que JavaScript.
