04 O QUE ACONTECE

JavaScript pede.
Lume calcula.

Geolocalização é uma API assíncrona do navegador: o JavaScript faz a solicitação após o clique e aguarda o consentimento. Em seguida, latitude e longitude são passadas como números f64 para a função exportada analyze_location, executada no WebAssembly. Essa função determina norte/sul e leste/oeste. Só depois o MapLibre abre o estilo Liberty do OpenFreeMap e solicita os dados da área visível. O mapa usa dados cartográficos do OpenStreetMap.

// Executado no módulo WebAssembly
fn analyze_location(latitude: f64, longitude: f64) -> i32 {
  if latitude >= 0.0 {
    if longitude >= 0.0 { return 0; }
    else { return 1; }
  } else {
    if longitude >= 0.0 { return 2; }
    else { return 3; }
  }
  return 0;
}

O navegador controla a permissão, precisão e disponibilidade do sensor. Se você negar acesso, a página não solicita dados do mapa; ela trata o erro e você pode tentar novamente.
