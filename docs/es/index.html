UN EXPERIMENTO PARA LA WEB

Código claro.
Se ejecuta en tu navegador.

Lume es un lenguaje de sintaxis sencilla que compila programas a WebAssembly. Explora el prototipo, lee el código y prueba ejemplos en tu navegador.

↓ Descargar código fuente (.zip) Abrir el playground ↗

Instantánea de la rama main. No es un instalador nativo.

ESTADO / 01 Prototipo abierto

Compilador JavaScript sin dependencias externas, salida WebAssembly y un puente controlado a las API del navegador.

WASM → Worker → DOM tipado

01 / PRUÉBALO

Ejecútalo localmente

Extrae el ZIP, abre una terminal en la carpeta del proyecto e inicia un servidor HTTP local con Python 3. No hace falta instalar paquetes npm.

unzip lume-language-main.zip
cd lume-language-main
python3 -m http.server 8000

Después abre http://localhost:8000 en un navegador moderno compatible con WebAssembly y Web Workers.

02 / EXPLORA

Un lenguaje pequeño

El prototipo incluye funciones, variables, condicionales, bucles, tipos i32, f64 y bool, ejemplos de Canvas y una API DOM con destinos registrados.

El heap experimental almacena celdas i32 mediante handles opacos. No ofrece cadenas, punteros sin procesar ni acceso directo a la memoria WASM.

03 / LEE ANTES

Límites y seguridad

WebAssembly y Web Workers no son, por sí solos, una sandbox para código malicioso. Ejecuta solo programas que entiendas y controles; el código puede consumir CPU hasta que se detenga.

La revisión y los límites implementados reducen riesgos conocidos, pero no garantizan que no existan vulnerabilidades. WASM tampoco es siempre más rápido que JavaScript.

04 / PRIMEROS PASOS

Empieza a usar Lume

Abre el playground de este repositorio o ejecuta el proyecto localmente. Elige un ejemplo o escribe tu programa en el editor; haz clic en Compilar para validarlo y en Ejecutar para correrlo en el navegador.

Para ejecutarlo localmente, descarga el código fuente, inicia el servidor desde la carpeta del proyecto y abre la dirección local:

python3 -m http.server 8000

Después, abre http://localhost:8000 en el navegador.

05 / HELLO WORLD, LUME

Tu primer programa

fn main() -> i32 {
  print_i32(42);
  return 0;
}

Pega el código en el editor y haz clic en Ejecutar. La consola mostrará 42. El lenguaje todavía no admite cadenas de texto, por eso este ejemplo usa la salida numérica disponible.

06 / EN TU PROYECTO

Cómo añadir Lume

Lume todavía no es un paquete npm ni un runtime listo para instalar en otra aplicación. Usa este repositorio como punto de partida: adapta el compilador en src/compiler.js, el Worker en src/worker.js y proporciona en el host JavaScript las funciones importadas por tu programa.

Para experimentar sin integrarlo, usa el playground de este proyecto. No basta con añadir una etiqueta <script>: la ejecución depende del compilador, el Web Worker y las importaciones del host.
