STATUS / 01 Open prototype

Dependency-free JavaScript compiler, WebAssembly output, and a controlled bridge to browser APIs.

WASM → Worker → typed DOM

01 / TRY IT

Run it locally

Extract the ZIP, open a terminal in the project folder, and start a local HTTP server with Python 3. No npm packages are required.

unzip lume-language-main.zip
cd lume-language-main
python3 -m http.server 8000

Then open http://localhost:8000 in a modern browser with WebAssembly and Web Worker support.

02 / EXPLORE

A small language

The prototype includes functions, variables, conditionals, loops, i32, f64, bool, and string types, managed arrays and structs, Canvas examples, and a DOM API with registered targets.

The heap uses opaque handles and releases allocations when execution ends. It does not provide raw pointers or direct access to WASM memory.

03 / READ FIRST

Limits and security

WebAssembly and Web Workers are not, by themselves, a sandbox for hostile code. Run only programs you understand and control; code can consume CPU until it is stopped.

The review and implemented limits reduce known risks, but do not guarantee that vulnerabilities are absent. WASM is not automatically faster than JavaScript either.

04 / FIRST STEPS

Start using Lume

Open this repository's playground or run the project locally. Choose an example or write your program in the editor; create supporting files with ＋ Arquivo and compile imports across tabs. Click Compile to validate it and Run to execute it in the browser.

To run it locally, download the source, start the server from the project folder, and open the local address:

python3 -m http.server 8000

Then open http://localhost:8000 in your browser.

05 / HELLO WORLD, LUME

Your first program

fn main() -> i32 {
  print("Hello, Lume!");
  return 0;
}

Paste the code into the editor and click Run. The console will show Hello, Lume!.

06 / IN YOUR PROJECT

How to add Lume

Lume is not yet an npm package or a runtime ready to install in another app. Use this repository as a starting point: adapt the compiler in src/compiler.js, the Worker in src/worker.js, and provide JavaScript host functions for the imports used by your program.

To experiment without integrating it, use this project's playground. Adding a <script> tag alone is not enough: execution depends on the compiler, the Web Worker, and host imports.
